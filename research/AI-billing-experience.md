
# My assessment 2026-08-04



With Claude Pro at £18 per month ( £15 per month on an annual plan ) you are limited to use Anthropic models and there are time based limits but over all it does feel like good value for money and the performance was good - apart from experiencing outages. 

That said, I did also top-up my monthly subscription with a $20 overage charge, plus Anthropic added $75 of free overage. 

I think ...

- for intermittent users the Claude Pro monthly subscription at £18 per month is more than good enough.
- for most users the Claude Max 5x monthly subscription at £90 per month would be needed.
- for serious users the Claude Max 20x monthly subscription at £180 per month would be needed.

Although these Max 5x and Max 20x subscriptions seem quite expensive - they will allow users to get through lots of work.

Alternatively, there are also Team and Enterprise plans but realistically I don't think we will go there because we will probably use whatever comes with our Microsoft M365 contract.



---

With Openrouter there is no equivalent to the Claude Pro monthly subscription, instead it only offers PAYG / pre-payment billing - I did a $25 pre-payment which ended up costing $31.66 after taxes ( £24.02 ). 

You get access to various frontier and open-source models but your usage is metered so the costs vary depending on the models you use. 

I used the Claude code CLI-based harness to access the models using the Openrouter API. I found it somewhat confusing tbh, e.g. I was burning through tokens via Openrouter while using Claude code CLI-based harness without realising I was not using my Claude code tokens - had i known i could have switched to using lower cost open-source models. 

I would like to revisit using Openrouter and test it with a different CLI-based harness for coding in case I can get better value and performance. Over all it does feel like good value for money and the performance was good.

---

With Google Gemini there is no equivalent to the Claude Pro monthly subscription, instead it only offers PAYG / pre-payment billing. 

I had a few different Google accounts so it got rather confusing tbh because I also pay for other Google services e.g. photo storage. 

I think my total spend for Gemini coding assistance so far was £18.05 ( £8.14 in Jul and £9.91 in Aug ). I used the Gemini CLI-based harness called antigravity. 

PAYG does seem significantly more expensive than the Claude Pro monthly subscription - however compared to the cost of a human coder, it does feel like good value for money and the performance was good.

---

With Github Copilot Pro at $10 ( £7.46 ) per month you have access to various frontier and open-source models but your usage is metered so the costs vary depending on the models you use.

I was using GPT 5.4 ( probs the most expensive ) and I burned through my usage in less that 2 days!

Over all it *did not* feel like good value for money and the performance was terrible ( but tbf that could have been down to the way i was using it ).
